# PointGun 🎯

PointGun is a simple aim trainer game built using Python and Pygame.

## Features
- Start menu
- Settings system
- Sound effects
- Random target spawning
- Score tracking

## Controls
- Mouse: Aim
- Left Click: Shoot

## Installation

Clone the repository:

git clone https://github.com/DreigAguila/PointGun.git

Install dependencies:

pip install -r requirements.txt

Run the game:

python menu.py

## Technologies Used
- Python
- Pygame
